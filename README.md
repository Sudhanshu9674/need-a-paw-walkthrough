# Need a Paw? — product walkthrough

A screenshot walkthrough of **Need a Paw?**, a two-sided pet adoption app: how it
works for adopters, and how it works for shelters, rescues and breeders.

Open `index.html`, or read it on the published page.

The screens are captured from the running application against demo data. The
pets, organisations and people shown are fictional.

This repository contains the walkthrough only — no application source.
